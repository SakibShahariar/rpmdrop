# RpmDrop

A lightweight native GNOME application for inspecting and installing local RPM packages.

RpmDrop is a focused local-package installer for Fedora and other DNF5-based RPM systems. Its design prioritizes a clear review step before any system changes.

## Current implementation

- Open local RPM files from the application or desktop **Open With**.
- Optionally install the `rpmdrop-nautilus` subpackage to add **Inspect with RpmDrop** to GNOME Files for one or multiple selected RPMs. Remove that subpackage to disable the context-menu action without removing RpmDrop.
- Inspect package metadata, including version, architecture, vendor, packager, license, summary, and description.
- Review the package's declared RPM requirements and provided capabilities, separately from DNF5's resolved transaction.
- See distinct trusted, unsigned, unknown-key, digest-failure, signature-failure, and unavailable verification states with explanations.
- Preview DNF5-resolved package actions, including dependencies, upgrades, and removals.
- Install a reviewed transaction through the DNF5 daemon after explicit acknowledgement and Polkit authorization.
- View transaction progress and request cancellation during the download phase.
- Review a private local history of the last 100 package operations.
- Keep the GTK interface responsive while package inspection runs in the background.
- Queue multiple files opened together and inspect them one at a time.

The application resolves local RPMs through `dnf5daemon-server` and displays the resulting transaction, including package actions, versions, architectures, reasons, and reported sizes. Before installation, it re-resolves the goal and refuses to proceed if the transaction or warnings changed. Failed, unavailable, or indeterminate signature verification blocks installation; unsigned and unknown-key packages require a separate acknowledgement. The requirements shown in package details are the RPM's declared requirements; the separate preview is generated by DNF5. Cancellation is available during package downloads; DNF5 does not permit cancellation once the RPM transaction has begun. Recent operation history is stored in `~/.local/share/rpmdrop/history.sqlite3`, limited to the latest 100 operations, and protected with user-only file and directory permissions. It can be cleared from the History window.

## Initial scope

Fedora 44 is the first supported and CI-tested target. Other distributions may work if they provide GTK 4, libadwaita, RPM tooling, `dnf5daemon-server`, Python D-Bus bindings, and (for the Files action) `nautilus-python`, but they are not yet validated. Repository browsing, updates, and general package management are intentionally out of scope.

## Technology

- Python and PyGObject
- GTK 4 and libadwaita
- RPM tooling for read-only package inspection
- DNF5 daemon D-Bus API for transaction resolution, preview, and execution
- Polkit authentication mediated by the DNF5 daemon

## Development

The application requires Python 3, GTK 4, libadwaita, PyGObject, the RPM command-line tools, `dnf5daemon-server`, the system Python D-Bus bindings (`python3-dbus` on Fedora), and optionally `nautilus-python` for the Files context-menu extension.

Run the application from a checkout with:

```sh
python -m rpmdrop
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for development expectations, [docs/architecture.md](docs/architecture.md) for the security model, [docs/fedora-validation.md](docs/fedora-validation.md) for live-system validation, and [packaging/rpmdrop.spec](packaging/rpmdrop.spec) for the initial Fedora RPM packaging. A Fedora 44 CI job builds the RPM from the current source tree.

## Status

Early development. Package inspection, transaction preview, and the DNF5 installation flow are implemented. The full install path still needs manual validation on a real Fedora desktop with its DNF5 daemon and Polkit authentication agent.
